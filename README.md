# Tourist Stay Hub - Minimal Skeleton
This archive contains a minimal skeleton of the **Tourist Stay Hub** project:
- backend/service-auth (Spring Boot skeleton)
- backend/service-hotel (Spring Boot skeleton)
- backend/service-booking (Spring Boot skeleton)
- backend/service-gateway (Spring Cloud Gateway skeleton)
- frontend/react-client (Create React App-like skeleton)

These are starter templates to help you develop locally. They are **not** full-featured production apps —
they show project structure, basic controllers, and configuration to get you started.

## To use
- Java microservices: each backend subfolder contains a `pom.xml`. Import into your IDE (IntelliJ/Eclipse) and run.
- Frontend: `cd frontend/react-client` then `npm install` and `npm start`.
